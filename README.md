# OrcaOS

**OrcaOS** is a fedora-based GNU/Linux distribution designed to make Linux installation, configuration, and maintenance straightforward for beginners.

the goal is to provide an accessible Linux experience without sacrificing customization or control.

## planned features

- **simple installation:** a guided, beginner-friendly installation process.
- **easy maintenance:** simplified system updates, package management, and troubleshooting.
- **centralized configuration:** a graphical control panel for configuring tools such as hyprland, waybar, and other desktop components.
- **backup & recovery:** straightforward system backups and restoration.
- **customization:** desktop personalization without manually editing configuration files.

## development status

OrcaOS is in early development.

the repository currently contains Fedora Kickstart configurations for building custom installation images. the features listed above are development goals and are not yet fully implemented.
